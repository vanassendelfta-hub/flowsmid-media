# Flowsmid media

Beeld en video voor flowsmid.nl, geladen via jsDelivr (vastgepind op een commit).

- `werk/` – previews voor de portfoliopagina flowsmid.nl/werk: per site een kort fragment van de intro (`<id>.mp4`, 330x716) en een stilstaand beeld (`<id>.jpg`). Geknipt uit de reclamevideo met de intro's van de sites.

Vervang een bestand niet stilletjes: voeg een nieuwe versie toe en werk de commit in de pagina bij.
